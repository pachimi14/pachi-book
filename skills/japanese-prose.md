# japanese-prose：AIの日本語が滑りやすい箇所の点検

書き手は毎話これを読んでから書き、書いた後に点検する。独立レビューは「重大な欠陥」の判断にこれを使う。
目的は、AIの文章に特有の型を消すこと。勢い・軽口・誇張・溜めを削るための規則ではない。

出典：Lulu Book の kakuyomu-prose-writing（japanese-tech-writing、ai-tic-baselines、sentence-level、causal-pragmatic、evidence-dialogue、episode-preflight）から、小説に効く部分だけを抜き出した。

## 1. 対句否定（最優先で消す）

「Aではない。Bだ」「Aというわけじゃない。Bだ」の型。AIの文章で最も頻出し、最も目立つ。

- **地の文では書かない。** Bをそのまま書く。Aは書かない。
  - 悪い：それは恐怖ではなかった。高揚だった。　→　良い：胸の奥が跳ねた。高揚だ。
  - 悪い：怖くないわけじゃない。それでも足は前に出た。　→　良い：膝が笑っている。それでも足は前に出た。
  - 悪い：守るためではなく、見るために来た。　→　良い：見に来ただけだった。
- **同じ族として扱う型**：〜ではない／じゃない、〜わけではない／わけじゃない、〜のではない／んじゃない、AではなくB／AじゃなくB、AというよりB、AでもBでもない／Aでもなければ、〜だけではない、決して〜ない、ただ〜だけだ。字面が違っても「否定を踏み台にして結論を強調する」ものは同じ。
- **台詞では、直前に相手が実際に言った・思っていることを打ち消すときだけ使ってよい。** 誰も言っていないAを否定する台詞は書かない。
- 慣用句（「〜している場合ではない」「それどころではない」）は対象外。
- `check_episode.py` が1件ずつ行番号付きで出す。地の文は ERROR、台詞は WARN。

## 2. AIっぽい空句

- 予告と総括：「重要なのは〜」「〜に他ならない」「要するに」（直前の言い換えだけのとき）
- 姿勢だけの宣言：「正面から受け止める」「向き合う」（何をしたかを書かない場合）
- 中身のない強調：「不可欠」「根本的な」「決定的な」「非常に」「極めて」
- 何をしたか分からない動詞：「言語化する」「噛みしめる」（何を、が無いとき）
- 「そう、〜」で始める相槌の地の文、「まるで〜のような」の連打

## 3. 翻訳調の比喩と擬人化

- 英語慣用句の直訳（運ぶ、開かれた、住む、着地する）を日本語の比喩として使わない。
- 抽象物が意思を持つ文（「沈黙が語った」「空気が告げていた」）を、人か物の具体的な動作に戻す。
- 判定：その述語を字義どおりの動作として想像できてしまうなら疑う。主体と対象を具体語で言い直せるなら、言い直しを書く。言い直せないなら、その文は中身が決まっていない。

## 4. 一文の点検

- 誰が、何を、どうしたかが一意に分かるか。助詞と修飾の掛かり先が正しいか。
- 比喩を外しても、位置・接触・移動が成り立つか。物は開始位置から終了位置まで追えるか。
- 痛み・熱・圧力の原因と、感じる部位が合っているか。
- 指示語（それ、その、あれ）の指す先が近くで一つに決まるか。
- 接続詞の論理が成り立つか（「だから」は因果、「でも」は対立）。同時に起きただけの二つを接続詞で結ばない。

## 5. 繰り返しと説明

- 描写の直後に、同じ内容を要約し直さない。
- 同じ結論を、地の文・台詞・コメントで重ねない。
- 読者がすでに見た出来事を、台詞で解説し直さない。
- 設計資料の言い回し（「〜という選択」「主体性」など）を本文に漏らさない。

## 6. 台詞

- 各台詞が直前の何に応答しているか言えること。質問には、今それを聞く理由があること。
- 設定を説明させるためだけの質問を書かない。
- 感情や態度が切り替わるときは、その契機（出来事、相手の言葉）を置く。

## 7. 知識の範囲

- 一人称の主人公が、見た・聞いた・教わった・推測した以外のことを断定しない。
- 推測を、根拠なく断定に変えない。

## 8. 話末の引き

- 読み終えた読者が「次に何を確かめたいか」を一文で言えること。
- 引きは、その話の出来事から生まれていること。根拠のない不穏な一文だけに頼らない。
- 危機や寸止めに限らない。新しい目的、関係の変化、約束も引きになる。
