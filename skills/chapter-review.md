# chapter-review：章末の点検

章（約10話）の最後の話を採用したあとに行う。結果は `chapters/CH-nn.md` に書く。

1. **通し読み（独立した読み手）**
   新しい会話（Claude Code / Codex のどちらでもよい）または独立した読み手に、章の各話の採用版の本文だけを話順で渡す。concept・台帳・計画は渡さない。次を答えさせる：
   - どの話のどこで飽きたか、読み飛ばしたくなったか
   - 意味が取れなかった箇所
   - 各話の終わりで次を読みたかったか（はい／いいえと理由）
   - 章を読み終えて、この作品の面白さを一言で
2. **伏線の棚卸し**：`threads.py` の一覧を見て、回収予定を更新する。3章以上放置のものはオーナーに判断を求める。
3. **反復の点検**：章内で、同じ報酬の型、決め台詞、比喩、展開の繰り返しを探して列挙する。
4. **正典の整理**：canon の古い状態・重複を整理する。
5. **次章計画**：次章の目的、終わり方、ブロック割り、張る・回収する伏線を `chapters/CH-(nn+1).md` に書き、オーナーと合意する。

報告は、1〜3の要点と次章計画案だけを短く伝える。
