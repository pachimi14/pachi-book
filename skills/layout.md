# layout：行・空行・区切り・表記の既定値

毎話、書き手が読む。作品の `style.md` に「作品固有の表記」があれば、そちらを優先する。
`check_episode.py` がこの内容を機械的に点検する（作品の style.md から場面転換記号を読む）。

根拠：カクヨムの AI 利用申告なし70作の EP1〜2 を、空行・字下げを保持して取得した実測（lulu-market-research-pilot-upload/blankline_sample、2026-09-25）。

## 1. 行

- 行は改行一つで区切る。1行は1〜2文が目安。3文以上を1行に続けるのは、同じ動作が一続きのときだけ。
  - 実測：1行あたりの文数は作品中央値1.3、一文だけの行は中央値78%。
- 120字を超える行は作らない（スマホで数行に折り返す。実測の作品中央値は0%）。
- 地の文の行頭は字下げしない（作品の style.md で変更可）。

## 1b. 地の文の運び

- 同じ時間・動作の流れの2文は、1行に続けて書く（「足元の舗装に亀裂が走る。だが、肘は一ミリも下がらない。」）。1文ごとに改行しない。
- 溜めの短い一行（「来た。」「同時だった。」）は見せ場だけに使う。1話に数か所。
- 「主語が、」「目的語を、」のような短い区切りで読点を打たない。
- `check_episode.py` が地の文の 文/行（1.2未満、1.55超で WARN）、10字以下の行の割合（2割超で WARN）、読点/文（0.85超で WARN）、「主語が、」型の行数（20行以上、5行未満で WARN）を出す。
- 根拠：kyuketsu-mahou-syojo04 で、EP001〜004（文/行 1.3〜1.4、短い行 1割前後、読点 0.6〜0.8）から EP005〜008 にかけて細切れの文体へずれた（2026-09-26）。直前話だけを見本にすると、ずれが積み重なる。

## 2. 空行

| 段階 | 使う場所 |
|---|---|
| 空行なし | 同じ時間・場所・動作の流れの行。台詞と、それを言った人の直後の動作 |
| 空行一つ | 地の文と台詞の境目（実測でほぼ100%）。同じ場面の中で注意や行動のまとまりが変わる箇所。擬音や短い一行を立たせる箇所 |
| 空行二つ | 配信コメント・掲示板・画面表示への出入り。後書きの前 |
| 場面転換記号 | 場面・時間・視点・回想の切り替え（下の3節） |

- 溜めのための大きな空白は、明かす一行や決定的な一行の直前だけ。1話に数回まで。
- 「翌日」「数時間後」など時間が飛ぶ行を、普通の空行で済ませない。

## 3. 場面転換

- 作品の style.md の「場面転換記号」を使う（既定は `◇`）。
- 書き方：空行一つ、記号だけの行、空行一つ。
- 同じ作品で別の記号（◆、＊、☆など）を混ぜない。

## 4. 表記

| 項目 | 規則 |
|---|---|
| 台詞の末尾 | 句点を付けない（「行くぞ」）。 |
| ！？ | 全角。「！？」の組み合わせも全角。半角の!?は使わない |
| ！？の後 | 同じ行で文が続くときは全角スペースを入れる（「はっ！　えっ？」）。行末、閉じ括弧の前には入れない |
| 数字 | 地の文と台詞は漢数字（十年、三十過ぎ、一ミリ）。配信コメント・掲示板・画面表示は算用数字も可 |
| 三点リーダ・ダッシュ | `……` `――`（偶数個） |
| 擬音 | カタカナ。独立させるときは1行にする |
| ルビ・傍点 | `|親文字《ルビ》`、`《《対象》》` |
| Markdown | 本文に入れない |

## 5. 括弧の役割

| 括弧 | 用途 |
|---|---|
| 「」 | 声に出した台詞 |
| 『』 | 特定の相手にしか聞こえない声（念話など）、電話・通信越しの声、作中作品名 |
| 〈〉 | 配信のコメント（1行1コメント） |
| 【】 | 掲示板のスレッド名、システム・画面の表示 |
| （） | 使わない。心の声は地の文に溶かす |

作品によって『』の対象（誰の声か）が違うので、作品の style.md に書く。

## 6. ファイル形式

- 本文ファイルには本文だけを書く。話のタイトル、前書き、後書きは入れない。
  - 例外：作品の style.md に「本文の1行目にタイトル：あり」と書いた作品は、1行目に「第N話　サブタイトル」、2行目を空行にして本文を始める。
- タイトルはブロックのメモの各話の見出しか notes/summary.md の「題名」欄に「第N話　サブタイトル」の形で書き、投稿時に入力する。
