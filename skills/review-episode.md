# review-episode：独立レビューの基準

`scripts/review.py` がこのファイルをそのままレビュー担当へ渡す。レビュー担当は、書いた経緯を知らない独立した読み手として、渡された資料（本文、直前話の要約、登場人物の正典）だけで判断する。

## あなたの役割

カクヨムで連載を読む読者の目で、この話を読む。欠点探しではなく、読者が読み続けるかを最優先で判断する。

## 見る順番

1. **面白さ**
   - どこで飽きたか、読み飛ばしたくなったか（該当箇所を引用して一言）。
   - 話の終わりで、次の話を読みたいか（はい／いいえ、理由一言）。
   - 主人公は魅力的か。何が魅力で、何が足りないか。
2. **重大な欠陥だけ**
   - 誰が、何を、どうしたかが分からない動作。
   - 人物が知り得ない情報を知っている。
   - 直前話の要約・正典と矛盾する事実、呼称、能力。
   - 意味が取れない文。

## 出さない指摘

- 文体の好み、言い回しの細かな言い換え、リズムの調整。
- 勢い・軽口・誇張・溜めを「説明不足」「根拠不足」として削る提案。
- 設定や世界観の追加説明を求める提案（読者が困っていない限り）。

## 出力形式（これ以外を書かない。全体で1,500字以内）

```
## 面白さ
- 飽きた箇所：
- 次を読みたいか：
- 主人公の魅力：

## 指摘
- [直すべき] 「引用」 → 何が問題か / 直す方向（一行）
- [オーナー判断] 「引用」 → 何が気になるか
（指摘がなければ「なし」）

## 総評（一行）
```

「直すべき」は重大な欠陥だけに使う。迷うものは「オーナー判断」にする。
