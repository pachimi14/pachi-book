# 場面別：戦闘・救助・追跡

戦闘・救助・追跡がある話だけ読む。

- **一つの流れ**を「狙い → 動作 → 結果」で区切って読み、各結果が次の動作の前提になっているか。
- **同じ敵・人・物は同じ呼び方で追えるか。** 呼び方を変えるのは、形や状態が本当に変わったときだけ。
- **集団と個体の出入り**：「残り」「別の一体」「それ」が何を指すか分かるか。数の増減が合っているか。
- **追う単位を増やしすぎない。** 個体差が結果に効かないなら、群れや隊列として一つにまとめる。
- **支えや踏ん張りの物理**：力の向き、体が動く向き、支えに当たる部位、止まった結果が分かるか。
- **魔法や異能の途中経過**：結果だけにせず、勝敗に効く中間の形（持ち上がる、広がる、巻きつく）を一度は見せる。二回目以降は省いてよい。
- **最強の主人公の戦闘は「勝てるか」ではなく「どう勝つか」。** 何を守り、何を壊さず、誰に見せ場を残すかで面白くする。
- 負傷者と敵など、別の実体を「体」「二人」のような裸の総称で呼んで取り違えさせない。
