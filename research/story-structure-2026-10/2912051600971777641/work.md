# 悪ノ魔法少女ノワールは光堕ちを所望する

★275・公開 2026-09-01・公開話数 10・印を付けた話 10

## 線（作品を通して変わるもの）
- **力・正体**：1話 記憶なしで目覚め、組織製と知って演技を決める → 2話 光の技を大斧で呑む → 6話 政府の評価が「暫定A級以上」 → 7話 転移と、最大技を受けきる力が分かる → 10話 世間が「人間の可能性が高い」と整理する。表れ方：等級（数字）と、能力が分かっていくこと
- **世間の目**：2話 星彩姫2人だけが認識 → 6話 前回は情報規制、今回は全国生配信 → 8話 全国へ処刑を宣言 → 10話 指名手配、掲示板では憎悪と人気が混ざる。表れ方：世間の呼び名（「深淵教団の星彩姫」→「悪の星彩姫」）
- **立場・所属**：1話「最高傑作」 → 3話 首領のお気に入りだが幹部に疑われる → 5話 殺害命令 → 9話 次は首級を捧げるか、自分の首が代わりになる。表れ方：呼び方と、課される条件
- **穢魔との関係**：3話 裏切りに賛成する話し相手 → 4話「一心同体」 → 8話 暴走し、主人公が「お願い」と頼んで止める。表れ方：頼みごとの向き
- **敵・謎**：1話 首輪 → 3話 洗脳の定着率を疑われる → 9話 首領が「黒き月」と呼ぶ。表れ方：呼び名と、秘密の範囲
- 脱出計画（4話）と生活（5話）は1段だけ

## 章と山場
- 章の区切りはない（1〜10話で1ブロック）
- 問いと答え：5話の殺害命令 → 8話で殺さずに撤退。9話の「首級を捧げる」は答えの出ないまま残る。2話の「ただの敵なのか」もまだ答えが出ていない
- 山場は7話だけなので、間隔は出せない

## ブロックの回し（型の並び）
- 並び：設定1 → 事件2 → 事件3 → 日常4 → 設定5 → 事件6 → 山場7 → 事件8 → 事件9 → 外の反応10
- よくある並び
  - ①命令 → 出撃 → 帰還して幹部と対峙（1-2-3、5-6〜8-9）
  - ②出撃 → 帰還 → 戦闘のない回（2-3-4、8-9-10）
  - ③事件 → 山場 → 事件（6-7-8）
- 同じ型の最長連続：事件の2話（2-3、8-9）
- 外の反応：独立した回は10話（掲示板）。話の中の数行は5話（テレビ）、6話（報道ドローン）、7話（報道陣の悲鳴）

## 日常回
- 4話の1話だけ（10話中10%）
- 置き場所：帰還と調整室（3話）の直後、命令の回（5話）の前
- 進んだ線：脱出計画（なし → 偵察を始める）、穢魔との関係（→「一心同体」）

## 関係の進展と表れ方
- **矢代カナタ**：5話 殺害対象 → 6話 敵同士として名乗り合う（投降を求められ、「供物」と返す） → 7話 カナタが見とれて動揺する → 8話 主人公が気絶中のカナタを殺さず、瓦礫の陰へ庇う（行動で表れる）
- **日向ヒカリ**：2話 初対面。手加減に違和感を持つ（「ほっとしたように見えた」） → 8話 再び救援に来て「どうしてこんなことを」と問う
- **内なる穢魔**：3話 → 4話 → 8話（線の節と同じ）
- 再演
  - 8話：2話と同じく増援を待って撤退するが、今回は負傷が撤退の口実になる
  - 9話：3話と同じく幹部に責められるが、首領が介入して結果が変わる

## 引き
- 分布：危機 4（3・5・7・9話）、約束・予告 2（1・6話）、笑い 2（4・10話）、問いが残る 1（2話）、関係が動く 1（8話）
- 同じ型の連続はない（最長1）。危機は1話おきに来る
- 最後の話（10話）の引き：笑い

## 序盤（1〜3話）
- **1話**：主人公の出自（元男性・組織製）、首輪、演技の決意、博士、出撃命令を出す。戦闘、星彩姫側、穢魔はまだ出さない
